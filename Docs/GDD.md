# 넥서스 부수기 (Nexus Breaker) — GDD v0.3

2D 도트 · 포스트 아포칼립스 · 데스크톱 아이들러. Unity 6000.3.5f2 (2D URP). 타겟: Windows / Steam.

## 한 줄 컨셉
세상의 물자를 빨아들여 문명을 무너뜨린 체력 10억 넥서스를 수리공이 망치로 부수고,
튀어나온 물건을 폐버스 노점에서 **내가 정한 가격**에 팔아 다시 부수기에 투자한다.

## 코어 루프
```
타격(클릭+자동) → 넥서스 HP↓ → 박스 드랍 → 창고 → 상점 진열·가격 책정
→ AI 손님 구매 → 너트(화폐) → 업그레이드 → 타격 효율↑ → … → 넥서스 파괴 → 환생(다음 지역)
```

## 세계관
- 넥서스 추락 → 지구의 물자를 흡수 → 문명 붕괴. 남은 건 폐허와 생존자.
- 넥서스를 부수면 흡수된 물자가 쏟아진다. 물자가 귀한 세상이라 과자·담배가 귀중품.
- 깊이 팔수록(HP↓) 외계 물건 비율↑ (지층 개념).
- 화폐: **너트(Nut)**.

## 지층 (HP 구간)
| HP | 지층 | 박스 등급 확률 (일반/고급/희귀/외계/???) |
|---|---|---|
| 100~70% | 외피 | 85 / 13 / 2 / 0 / 0 |
| 70~40% | 압축층 | 60 / 30 / 8 / 2 / 0 |
| 40~10% | 내핵 | 35 / 35 / 18 / 11 / 1 |
| 10~0% | 코어 | 15 / 30 / 25 / 25 / 5 |

넥서스 파손 비주얼 5단계: 100~80 / 80~60 / 60~40 / 40~20 / 20~0 (s0~s4).

**지층 경도**(데미지 배율): 외피 ×1 / 압축층 ×0.2 / 내핵 ×0.045 / 코어 ×0.012.
깊은 지층의 비싼 박스로 수입이 약 30배 뛰는 걸 상쇄해서, 후반이 순식간에 끝나지 않게 한다.
밸런스 시뮬레이션(클릭 없는 방치 봇) 결과 첫 넥서스 파괴 약 29시간: 외피 9.5h → 압축층 7.7h → 내핵 7.3h → 코어 4.1h.
수치는 `Assets/Scripts/Data/Stats.cs`에서만 조정하고, 메뉴 `Nexus Breaker/Run Balance Simulation`으로 확인한다.

## 타격
- 데미지 소스: 클릭(능동) / 수리공 자동 스윙 / 조수(DPS).
- 치명타: 기본 5% 확률, 10배.
- 박스: 타격 N회(기본 20)마다 1개 + HP 1%마다 지층 박스 1개 확정(등급 한 단계 위로 굴림).
- 첫 넥서스(10억) 목표 플레이타임 약 30시간. 수치는 `GameBalance` ScriptableObject에서 튜닝.

## 상점 (핵심)
- 아이템 툴팁에 **시장가** 표시 (외계 물건 포함, 정확한 숫자).
- 플레이어가 가격 설정: 직접 입력 + 슬라이더 + % 버튼(-50/-20/시장가/+20/+50/x2).
- 낮게 → 빨리 팔림, 높게 → 느리지만 비싸게, 터무니없이 높게 → 아주 가끔(부자·수집가만).
- **진열대 칸 수 제한**(시작 6칸)이 핵심 딜레마: 비싼 물건은 칸을 오래 점유.
- 예상 판매 속도 표시: 즉시/빠름/보통/느림/매우 느림/기적.
- 판매 로그.

### 판매 로직
- 손님 도착: 평균 간격 8초(지수분포), 업그레이드로 단축.
- 손님은 진열대에서 최대 3개를 본다(선호 카테고리 가중).
- 각 아이템 WTP = 시장가 × 타입배수 × LogNormal(0, σ). `가격 ≤ WTP`인 것 중 (WTP-가격)/WTP 최대인 것 1개 구매.
- 일반 손님(σ 0.35) 구매 확률: 0.5배 ~98% · 0.8배 ~74% · 1.0배 50% · 1.5배 ~12% · 2배 ~2% · 3배+ ≈0.

### 손님 타입
| id | 이름 | 배수(중앙값) | σ | 특징 / 등장 |
|---|---|---|---|---|
| survivor | 생존자 | 1.0 | 0.35 | 생필품 선호, 기본 |
| merchant | 떠돌이 상인 | 0.8 | 0.25 | 싼 물건 노림 |
| raider | 약탈자 | 0.6 | 0.30 | 깎으려 함 |
| soldier | 군 잔당 | 1.05 | 0.30 | 건전지·통조림 선호 |
| cultist | 넥서스 교단 | 1.0 (외계 2.0) | 0.40 | 외계 물건 선호 |
| collector | 수집가 | 3.0 (희귀 이상) | 0.60 | 3% 확률 등장 |
| alien | 변장한 외계인 | 5.0 (외계) | 0.50 | 내핵 도달 후 1% |

### 시장가 변동
- 5분마다 ±10% 랜덤워크(기준가의 0.5~2배로 제한).
- 이벤트(예: 모래폭풍 → 생수·방독면 필터 +80%, 10분).
- (선택) 같은 물건 연속 판매 시 일시 하락.

## 업그레이드 (너트 사용처)
- 타격: 망치 등급(클릭·스윙 데미지), 공격 속도, 조수 고용/강화, 치명타 확률.
- 박스: 드랍 주기, 고등급 확률, 창고 용량.
- 가게: 진열대 칸, 손님 유입, 오프라인 판매 효율.
- 비용 공식: `cost(L) = base × growth^L` (기본 growth 1.15).

## v0.2 — 첫 1시간을 재밌게
### 약점 (화면을 보는 플레이어 보상)
- 튜토리얼이 끝난 뒤 평균 80초(최소 25초)마다 넥서스 결정 위에 **빛나는 균열**이 생기고 7초 뒤 사라진다.
- 클릭하면 클릭 데미지 ×30(치명타 연출) + 지층 박스 1개(등급 한 단계 위, 창고가 가득 차도 들어옴).
- 실시간에만 생긴다(오프라인 정산 없음). 수치: `Stats.WeakPoint*`.

### 의뢰 (3칸, 10~20분짜리 짧은 목표)
- 종류: 카테고리 N개 팔기 · 특정 물건 N개 팔기 · 시장가 ×1.3 이상으로 N개 팔기 · (등급 이상) 박스 N개 열기 · 판매로 N 너트 벌기 · 직접 N번 때리기 · 약점 N번 깨기.
- 목표는 **지금 경제 속도**(박스·손님 속도, 지층별 드랍 비율)로 약 15분 분량이 되게 계산 → 초반·후반 모두 비슷한 시간.
- 보상: 판매형은 목표 물건 시장가 합의 60%, 너트 벌기는 목표의 30%, 박스·클릭·약점형은 박스.
- 다 하면 HUD에 "의뢰 완료! 보상 받기"가 깜빡이고, 보상을 받으면 45초 뒤 새 의뢰. 바꾸기는 5분에 한 번 무료.
- 환생하면 의뢰를 새로 받는다(경제 규모가 바뀌므로). 오프라인 판매도 진행에 들어간다.
- 밸런스(시뮬레이션, 1분마다 보상 받는 봇): 첫 넥서스 28.7h → 25.9h, 의뢰 보상은 총수입의 약 10~15%.

### 도감
- 등급별 칸(못 찾은 물건은 실루엣), 등급 완성 표시, 물건별 기록(얻은 수·판 수·최고 판매가).

## 환생
- 넥서스 파괴 → 넥서스 코어 획득 → 다음 지역(HP ×10).
- 지역: 폐허 도시(10억) → 사막 고속도로(100억) → 핵겨울 항구(1조) → 궤도 엘리베이터 잔해(10조).
- 유지: 코어 영구 강화, 도감. 초기화: 너트, 업그레이드, 재고.
- 큰 수: `double` 사용(최대 ~1e308). UI는 단위 접미사(만/억/조/경 …).

## 오프라인
- 종료 시각 저장 → 재실행 시 경과 시간(최대 8시간, 업그레이드로 확장)만큼 데미지·박스·판매 시뮬레이션 후 정산 팝업.

## 데스크톱 형태
- 기본: 화면 하단 가로 띠 창(내부 384×96, 3배 = 1152×288), 투명 배경, 항상 위, 클릭 통과 토글.
- 좌측 넥서스·수리공, 우측 노점·손님 줄.
- 상점 버튼 → 창이 위로 커지며 상점 페이지(내부 384×216, 3배 = 1152×648).
- Win32: `SetWindowLong`(WS_EX_LAYERED|WS_EX_TRANSPARENT), `DwmExtendFrameIntoClientArea`, 카메라 배경 알파 0.
  클릭 통과 중에는 `GetCursorPos` 폴링으로 UI/캐릭터 위일 때만 통과 해제.
